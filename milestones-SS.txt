Milestone reflection:
This milestone was primarily about data work. The hardest part was figuring out how to get walking distances without using Google's paid API feature.
Overpass Turbo gave us coordinates and OSRM's Service gave us walking distances based on actual real-life sidewalks. 
Two issues that came up: httplib needed a special compile flag for HTTPS and OSRM only accepts 100 coordinates per request so we had to split into chunks.
Both issues are now solved. Next up is writing a Graph class and Dijkstra so we can actually route between buildings, then plugging it into Leaflet for the web map part.

Progress Summary:
